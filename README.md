# NutriFlow ERP

Protótipo inicial de um ERP para distribuidora de ração.

## Publicação

Este projeto é estático nesta primeira fase. Para publicar na Vercel, importe o repositório no painel da plataforma e mantenha `main` como branch de produção. Cada envio para essa branch atualiza o site automaticamente.

## Próximas etapas

- Autenticação segura e perfis de acesso
- Banco de dados e cadastros reais
- Pedidos, estoque e financeiro
- Integração fiscal NF-e e MDF-e
- Portal/PWA para vendedor externo
